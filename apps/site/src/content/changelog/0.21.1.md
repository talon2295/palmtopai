---
date: 2026-10-16
summary: Small fixes to pairing, syncing and the command line.
---

- A device that never saw the confirmation of a change and sends it again is now told it is
  already there, instead of getting an error.
- When your phone switches back to a project it asked for just before, it asks for it again
  instead of staying empty.
- A failed write of the list of paired devices no longer blocks the ones after it, and the
  computer goes back to what is saved on disk.
- Commands that take `--session` find the session in any project of the computer when you run
  them outside a project folder, and `palmtop share close` checks the session before asking you to
  confirm.

Run `palmtop update`.
