- **Codex**: `palmtop install` sets up Codex too when it is on your computer: the `palmtop` skill
  (type `$palmtop`, or just ask) and a rule that lets Codex run `palmtop` commands without asking.
  See [Agents](/docs/agents#codex).
- `palmtop install` sets up the agents it finds on your computer, Claude Code and Codex, and
  `palmtop update` updates the skill of both.
