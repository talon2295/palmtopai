date: 2026-10-17
summary: palmtop on Windows, in PowerShell, without WSL.
---

- **Windows without WSL**: install in PowerShell with `irm https://palmtop.mtwa.it/install.ps1 | iex`.
  It needs Windows PowerShell 5.1 or newer and Node.js 22: no Git, no administrator rights, and
  it checks the download before it installs. The daemon, the command line, pairing, sharing and the
  tools for your agent work the same as on macOS and Linux.
- `palmtop setup` creates `palmtop.cmd` and, when you say yes, puts its folder first in your user
  `Path`. The old value is saved in a file first; without a terminal, it prints the one line to run
  by hand.
- **`palmtop stop` stops the daemon cleanly on every system**: it asks the daemon, instead of
  sending a signal that Windows doesn't have. A daemon from an older version is still stopped.
- **Your data stays yours on Windows**: the folder `%USERPROFILE%\.palmtopai` is limited to your
  Windows user and the system.
- A project is the same project whatever the case and the slashes of its path, as Windows treats
  them.
- Messages that tell you a port is taken or reserved by Windows say what to change
  (`localPort` in `config.json`).
- The home page shows the install command for the system you are on. WSL still works: use the
  macOS and Linux command inside it.

Run `palmtop update` on the computers you already have.
