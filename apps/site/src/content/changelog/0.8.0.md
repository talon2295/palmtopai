---
date: 2026-09-17
summary: A QR code in the terminal, and pairing links that work once.
---

- **`palmtop pair` shows the QR code in the terminal** as well as in the browser page, so you can
  pair even when no browser opens (in WSL, or in a remote shell).
- **A pairing link or QR code works once and expires**: it no longer carries the key of your
  checklists, only a single-use key that expires after a few minutes, so what stays on a screen,
  in a screenshot or in the history of a terminal can't be used again.
- From WSL, `palmtop pair` opens the page in your Windows browser (0.7.3).

Run `palmtop update`. Devices already paired keep working.
