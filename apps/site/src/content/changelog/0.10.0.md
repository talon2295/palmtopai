date: 2026-09-21
summary: One pairing per computer, and a new address.
---

- **Pair once per computer.** A paired device now sees every project of that computer, including
  the ones your agent starts later: no more scanning a QR code for each project. `palmtop pair`
  works from any folder and no longer creates a project.
- The selector under the title lists the projects of your computers, most recent first, with how
  many checks are still to review. **Follow activity** now keeps the device on the project *and*
  the session your agent is working in.
- **Delete this project…** in the ⋯ menu deletes a project from any device: sessions, checklists
  and reviews go on the computer too, your files are never touched.
- One notification switch per device, valid for every project of every computer you paired.
- palmtop moved to a new address. The old one keeps working for a few days,
  only to let installed versions update themselves.

**After updating you have to pair your devices again**, and the checklists on your computer are
reset: this version changes how pairing works and does not carry the old data over. Run
`palmtop update`, then `palmtop pair` and scan the QR code with each device.
