- The agent guide and the Claude Code skill now only use checklists of things to verify or test.
  Plan checklists, to approve work before the agent starts, are gone.
- Marks have one meaning: ✓ it works, ✕ it doesn't work, ? you need more information. The agent
  follows your note: a change to make, a feature to remove, a partial problem to fix. A question
  never changes code unless you ask. An unmarked check is not tested yet.
- palmtop is for every device, not just your phone: phone, tablet or a browser on your computer.
- New website with documentation and this changelog.

Run `palmtop update`: it also updates the Claude Code skill.
