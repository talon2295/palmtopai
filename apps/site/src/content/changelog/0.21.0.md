- **Tools for your agent**: Claude Code and Codex now get palmtop as an MCP server (`palmtop mcp`).
  The agent starts a session, writes checklists, asks questions and reads your review with tools
  instead of typing commands. What it writes arrives as it is, with quotes, `&`, `$` or accents,
  on any system.
- The tools keep the session of the conversation: the agent doesn't have to carry a session ref
  around, and finds it again with `session_list` if it ever loses track.
- Pairing, inviting, deleting and stopping to share stay commands that only you run: the agent has
  no tool for them.
- `palmtop setup` and `palmtop update` set it all up: the tools, their permissions and the new
  guide. Restart Claude Code, or start a new Codex session, after updating.
- `palmtop guide` is written for the tools, and ends with the matching commands for agents that
  have none.
